# RUNNER · Day 06

3라인 러너. 서브웨이 서퍼 스타일로 좌우 라인을 옮기며 장애물을 피하고 코인을 먹는다.
의사 3D(원근) 도로 위로 장애물이 다가온다.

## 조작

- **← →** : 왼쪽/오른쪽 라인 이동
- **↑ / Space** : 점프 (낮은 바리케이드를 넘는다)
- **↓** : 슬라이드 (머리 위 장애물 아래로 지나간다)
- 모바일: 화면 **스와이프**(상/하/좌/우)만으로 조작 — 버튼 없음. 탭하면 시작/재시작
- 점수·시간·목숨 UI는 게임 캔버스 안에 표시된다.

## 장애물

| 종류 | 색 | 회피법 |
| --- | --- | --- |
| 벽(BLOCK) | 빨강, 높음 | 다른 라인으로 이동 |
| 낮은 바리케이드(LOW) | 노랑 | 점프 |
| 머리 위 빔(HIGH) | 보라 | 슬라이드 |
| 코인 | 금색 | 같은 라인에서 획득 |

- 라이프 3개, 부딪히면 하나 감소하고 잠깐 무적.
- 달릴수록 속도가 붙는다. 점수는 이동 거리 + 코인.
- 최고 점수는 브라우저에 저장(localStorage)된다.

## 구조

```
day06-runner/
├── index.html          # 마크업 + 진입점 로드
├── css/style.css
└── src/
    ├── config.js       # 상수 (도로/원근/속도/스폰/색상)
    ├── projection.js   # (라인, 거리) → 화면 좌표 원근 변환 (순수 함수)
    ├── player.js       # 라인/점프/슬라이드 상태 모델
    ├── spawner.js      # 장애물·코인 행 생성 (항상 통과 가능한 라인 보장)
    ├── game.js         # 고정 스텝 루프 · 충돌 · 점수/라이프
    ├── renderer.js     # 하늘/도로/장애물/러너/이펙트 (상태 읽기 전용)
    ├── input.js        # 키보드 · 터치 버튼 · 스와이프
    └── main.js         # DOM 연결 진입점
```

의존성 제로. ES 모듈 + 관심사 분리. 상수 모듈이 최하단, 렌더러는 상태를 읽기만 한다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 실행한다.

```bash
cd day06-runner && npx serve .
# 또는
python -m http.server 8000
```
