## 개발 적용 (Changelog)

### 2026-08-01 — 장애물 폭 축소 (라인 침범 제거)

- 장애물 렌더 반폭이 약 0.9 라인유닛이라 옆 라인 중심까지 침범해, 다른 라인에 있어도 시각적으로 겹쳐 보이던 문제 수정
- 반폭을 **0.44 라인유닛**으로 줄여 장애물이 자기 라인 안에 들어오도록 하고, 충돌 임계값(`LANE_HIT`)을 시각 폭(장애물 반폭 + 플레이어 반폭)에 맞춰 정렬 → 보이는 대로 충돌

### 2026-08-01 — 그래픽 개편 · 충돌/입력/UI 정비

- **회피 불가능한 벽 완전 제거**: 점프/슬라이드 지속시간을 행 간격(`ROW_FRAMES_MIN`)보다 짧게 고정 → 이전 액션이 안 끝난 채 다음 액션을 강요당하는 상황 제거. 반응형 봇(200ms 지연) 40회 × 30000프레임 완주 무실점 재확인
- **충돌을 시각 위치(laneX) 기반으로 변경**: 논리 라인(즉시 스냅) 대신 실제 보이는 위치로 판정 → "가운데 아니면 안 맞던" 문제 해결, 스치는 충돌도 반영
- **장애물이 카메라를 지나 화면 밖으로 흘러가게**(`PASS_D`): 끝에서 팝 하며 사라지던 것 제거, 배경처럼 자연스럽게 지나감. 슬라이드는 순수 플레이어 애니메이션으로 분리
- **그래픽 개편**: 석양 하늘 + 산 실루엣, 스크롤 도로 밴드(속도감), 네온 사이드 레일, 3D 프리즘 장애물(컨테이너/허들/게이트), 반짝이는 코인, 점프 스트레치·슬라이드 스쿼시 러너, 피격 시 화면 흔들림·고속 스피드라인
- **점수/시간/목숨 UI를 캔버스 내부로**: HTML 스탯 박스 제거, 캔버스에 직접 렌더. **시간(TIME)** 추가
- **모바일 스와이프 전용**: 컨트롤 버튼 제거, 스와이프(상/하/좌/우)만으로 조작. 터치가 페이지를 스크롤/바운스시키지 않도록 차단(`preventDefault` + `overflow:hidden`)
- **화면을 꽉 채우는 세로 레이아웃**(2:3), 고해상도(DPR) 렌더

### 2026-08-01 — 회피 불가능한 벽 수정

- **행 간격을 시간(프레임) 기준으로 변경**: 기존 거리 기준은 속도가 붙으면 행 사이 간격이 ~8프레임(0.13초)까지 줄어 물리적으로 반응 불가했음. 이제 `속도 × 프레임`으로 환산해 최소 ~0.57초 반응 시간 보장
- **연속 장애물 행이 안전 라인 최소 1개 공유**: 직전 행에서 안전했던 라인 하나를 반드시 비워, 반대편으로 순간이동해야 하는 배치를 제거
- 검증: 게임 로직에 반응형 봇(200ms 반응 지연) 투입, 40회 × 30000프레임 완주 무실점 — 회피 불가능한 행이 생성되지 않음을 확인

### 2026-08-01 — 초기 구현

- **의사 3D 도로**: `(라인, 거리) → 화면 좌표` 원근 변환(`projection.js`, 순수 함수), 소실점으로 수렴하는 도로·스크롤 차선 점선
- **3라인 이동**: 좌우 라인 전환(부드러운 보간), **점프**(낮은 바리케이드 회피)·**슬라이드**(머리 위 빔 회피)
- **장애물 3종 + 코인**: 벽(BLOCK, 라인 이동으로만 회피)·낮은 바리케이드(LOW, 점프)·머리 위 빔(HIGH, 슬라이드), 코인 획득
- **공정 스폰**: 매 행마다 최소 한 라인은 반드시 통과 가능하도록 보장, 거리에 따라 스폰 간격 축소
- **충돌**: 카메라 근처 깊이 창에서 라인·회피 동작 판정, 라이프 3개·피격 후 무적 깜빡임
- **속도 램프**: 이동 거리에 비례해 속도 상승, 점수 = 이동 거리 + 코인, **최고 점수 localStorage 저장**
- Canvas 렌더(석양 하늘·도로·장애물·러너·코인/피격 이펙트, 상태 읽기 전용), 키보드 + 모바일 터치 버튼 + **스와이프**
- ES 모듈 관심사 분리, 좌상단 홈 링크
