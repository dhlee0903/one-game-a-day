## 개발 적용 (Changelog)

### 2026-08-01 — 회피 불가능한 벽 수정

- **행 간격을 시간(프레임) 기준으로 변경**: 기존 거리 기준은 속도가 붙으면 행 사이 간격이 ~8프레임(0.13초)까지 줄어 물리적으로 반응 불가했음. 이제 `속도 × 프레임`으로 환산해 최소 ~0.57초 반응 시간 보장
- **연속 장애물 행이 안전 라인 최소 1개 공유**: 직전 행에서 안전했던 라인 하나를 반드시 비워, 반대편으로 순간이동해야 하는 배치를 제거
- 검증: 게임 로직에 반응형 봇(200ms 반응 지연) 투입, 40회 × 30000프레임 완주 무실점 — 회피 불가능한 행이 생성되지 않음을 확인

### 2026-08-01 — 초기 구현

- **의사 3D 도로**: `(라인, 거리) → 화면 좌표` 원근 변환(`projection.js`, 순수 함수), 소실점으로 수렴하는 도로·스크롤 차선 점선
- **3라인 이동**: 좌우 라인 전환(부드러운 보간), **점프**(낮은 바리케이드 회피)·**슬라이드**(머리 위 빔 회피)
- **장애물 3종 + 코인**: 벽(BLOCK, 라인 이동으로만 회피)·낮은 바리케이드(LOW, 점프)·머리 위 빔(HIGH, 슬라이드), 코인 획득
- **공정 스폰**: 매 행마다 최소 한 라인은 반드시 통과 가능하도록 보장, 거리에 따라 스폰 간격 축소
- **충돌**: 카메라 근처 깊이 창에서 라인·회피 동작 판정, 라이프 3개·피격 후 무적 깜빡임
- **속도 램프**: 이동 거리에 비례해 속도 상승, 점수 = 이동 거리 + 코인, **최고 점수 localStorage 저장**
- Canvas 렌더(석양 하늘·도로·장애물·러너·코인/피격 이펙트, 상태 읽기 전용), 키보드 + 모바일 터치 버튼 + **스와이프**
- ES 모듈 관심사 분리, 좌상단 홈 링크
