# Day 04 · 카드 게임 종합 (Card Games)

포커/카드 게임 모음. 허브에서 게임을 골라 플레이한다. 공용 카드 엔진(덱·카드·렌더) 위에
게임을 하나씩 붙여간다.

- **블랙잭** — 딜러와 21 승부
- **홀덤(Texas Hold'em)** — 봇 2명과 노리밋 대결 (블라인드·베팅·사이드팟·쇼다운)

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버가 필요합니다.

```bash
npx serve .
# 또는
python -m http.server 8000
```

## 구조

```
day04-cards/
├── index.html          # 허브 + 블랙잭 화면
├── css/style.css       # 카지노 펠트 테마
└── src/
    ├── config.js       # 상수 (수트·랭크·값·설정)
    ├── deck.js         # 카드 + 슈(여러 덱, 셔플, 드로우)
    ├── blackjack.js    # 블랙잭 로직 (핸드값·베팅·딜러 AI·정산)
    ├── poker.js        # 포커 핸드 평가 (7장 중 최고 5장)
    ├── holdem.js       # 홀덤 로직 (블라인드·베팅 라운드·사이드팟·봇·쇼다운)
    ├── render.js       # 카드 요소 + 블랙잭/홀덤 테이블 렌더
    ├── storage.js      # 칩 잔액 (localStorage)
    └── main.js         # 허브 라우팅 · 입력 · 연결
```

`config ← deck ← blackjack ← render/main`. 렌더러는 상태를 읽기만 함.

## 블랙잭

- 칩 1000으로 시작(저장됨), 칩으로 베팅 후 딜
- **히트 / 스탠드 / 더블**, 에이스 1·11 자동, 딜러는 17에서 스탠드
- 블랙잭(첫 2장 21)은 **3:2** 지급, 승 1:1, 푸시 반환
- 칩이 떨어지면 리필

### 조작

| 입력 | 동작 |
| --- | --- |
| 칩 버튼 / 올인 / 취소 | 베팅 |
| 딜 · Space/Enter | 딜 · 다음 판 |
| H / S / D | 히트 · 스탠드 · 더블 |
