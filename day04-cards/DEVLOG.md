## 개발 적용 (Changelog)

### 2026-07-30 — 홀덤 베팅 이펙트

- 베팅/콜/레이즈 시 좌석 위로 **+금액 플로팅**
- **칩 스택 시각화** — 보유 칩·베팅을 포커 칩 디스크 더미로(금액에 따라 색·개수)
- **올인** 시 "ALL IN" 플래시
- 핸드 종료 시 **승/패 배너**("이겼다!" / "졌다…")
- 내 좌석 강조(칩 크게)

### 2026-07-30 — 홀덤 개선 (렌더·표기·봇)

- **깜빡임 제거** — 전체 innerHTML 교체 → **증분 렌더**(HoldemView). 안 바뀐 카드는 DOM 요소 유지, 새 카드만 추가
- **족보 상세 표기** — "원페어 K (키커 A)", "투페어 K·7 (키커 A)"처럼 랭크·키커까지 → 왜 졌는지 명확
- **봇 강화** — 몬테카를로 **에퀴티(승률) 추정** + 팟오즈 기반 폴드/콜/레이즈, 가끔 블러프
  (AA 프리플랍 ~0.74, 72o ~0.25, 결정당 ~25ms)

### 2026-07-30 — 홀덤 (Texas Hold'em)

- **포커 핸드 평가기**(`poker.js`) — 7장 중 최고 5장, 9족보·키커·A-5 휠, 배열 비교
- **홀덤 게임** — 나 vs 봇 2명, 블라인드(10/20), 프리플랍~리버 4베팅 라운드,
  폴드/체크/콜/레이즈, **정확한 사이드팟**(all-in), 쇼다운 정산
- **봇 AI** — 프리플랍 핸드 강도 + 포스트플랍 족보 기반 폴드/콜/레이즈
- 테이블 UI(좌석·딜러 버튼·베팅·커뮤니티·팟), 봇 페이싱, 검증(40핸드 칩 보존·사이드팟)

### 2026-07-30 — 허브 + 블랙잭

- **카드 게임 허브** — 게임 선택 화면(블랙잭 플레이 가능 / 홀덤 준비 중)
- **공용 카드 엔진** — `deck.js`(여러 덱 슈·셔플·드로우), `render.js`(재사용 카드 DOM 요소)
- **블랙잭 완성** — 베팅(칩·올인·취소), 히트/스탠드/더블, 에이스 소프트/하드,
  딜러 17 스탠드, 블랙잭 3:2, 승/패/푸시 정산, 칩 localStorage 저장·리필
- 카지노 펠트 테마, 딜 애니메이션, 키보드(H/S/D · Space)
- 각 게임 좌상단 홈 링크
- ES 모듈 관심사 분리, GitHub Pages 배포
