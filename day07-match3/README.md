# MATCH 3 · Day 07

8×8 3매치 퍼즐. 인접한 두 블록을 바꿔 같은 색 3개 이상을 맞추면 사라지고,
위에서 새 블록이 떨어진다. 연쇄(캐스케이드)로 점수가 불어난다. **스테이지 10개** —
정해진 이동 횟수 안에 목표 점수를 넘기면 다음 스테이지로.

## 조작

- 블록을 **탭 → 인접 블록 탭**하면 교체 (또는 블록을 원하는 방향으로 **드래그/스와이프**)
- 매치가 안 되는 교체는 자동으로 되돌아온다(이동 횟수 소모 없음)

## 특수 블록 (매치 패턴으로 생성)

| 매치 패턴 | 생성 | 효과 |
| --- | --- | --- |
| 가로 4 | 줄(가로) | 그 **행 전체** 삭제 |
| 세로 4 | 줄(세로) | 그 **열 전체** 삭제 |
| 2 × 2 | 폭탄 | 주변 **3×3** 삭제 |
| 5 매치(가로/세로) | 레인보우 | **같은 색 전체** 삭제 |

- 특수 블록은 매치에 휩쓸리면 발동하고, 다른 특수 블록을 **연쇄**로 터뜨린다.
- 레인보우는 아무 블록과 **교체**하면 그 색을 전부 지운다.

## 구조

```
day07-match3/
├── index.html          # 마크업 + 진입점 로드
├── css/style.css
└── src/
    ├── config.js       # 상수 (격자/색/특수 종류/스테이지)
    ├── board.js        # 격자·매치 감지·특수 생성·중력/리필·리셔플 (순수 로직)
    ├── game.js         # 상태 머신·트윈·특수 발동/연쇄·점수·스테이지
    ├── renderer.js     # 보드·블록·특수 장식·연쇄 이펙트 (읽기 전용)
    ├── input.js        # 탭/드래그 → 교체
    └── main.js         # DOM 연결 진입점
```

의존성 제로. ES 모듈 + 관심사 분리. 상수 모듈이 최하단, 렌더러는 상태를 읽기만 한다.

## 실행

```bash
cd day07-match3 && npx serve .

```
