## 개발 적용 (Changelog)

### 2026-08-03 — 인게임 HUD · 특수 더블탭 발동 · 이펙트

- **HUD를 캔버스 안으로**: HTML 스탯 박스 제거, 캔버스 상단에 스테이지·점수·목표 **진행바**·이동 렌더(그리드는 그 아래로 오프셋, 보드 영역 클립)
- **특수 블록 더블탭/더블클릭 발동**: 특수 블록을 두 번 탭하면 제자리에서 즉시 터뜨림(이동 1 소모). 레인보우는 가장 많은 색을 제거
- **이펙트 추가**: 블록 제거 시 팝(확장 링), 줄 삭제 빔(가로/세로), 폭탄 링(확장 원), 레인보우 화면 플래시

### 2026-08-03 — 초기 구현

- **8×8 3매치 코어**: 인접 교체 → 매치 감지(가로/세로 3+) → 제거 → 중력/리필 → **연쇄(캐스케이드)**. 매치 없는 교체는 되돌림
- **2×2 스퀘어도 유효 매치**로 처리(라인 3매치와 별개)
- **특수 블록 생성 규칙**: 가로4 → 줄(행 삭제), 세로4 → 줄(열 삭제), 2×2 → 폭탄(3×3), 5매치 → 레인보우(같은 색 전체). 특수는 스왑 위치에 우선 앵커
- **특수 발동·연쇄**: 특수가 매치에 휩쓸리면 발동하고, 효과 범위에 든 다른 특수를 BFS로 연쇄. 레인보우는 스왑으로 색 전체 제거
- **스테이지 10개**: 이동 횟수 안에 목표 점수 달성 → 다음 스테이지, 실패 시 재시도. 캐스케이드 점수 배수
- **리셔플 가드**: 가능한 수가 없으면 색을 섞어 항상 진행 가능
- 상태 머신(idle→swap→clearing→falling→cascade) + 블록 트윈, Canvas 렌더(글로시 블록·특수 장식·연쇄 축소 이펙트), 탭/드래그 입력, 고해상도(DPR)
- 검증: 헤드리스 로직 테스트(매치 감지·특수 생성·연쇄·중력·4000수 안정성) 통과, 브라우저 콘솔 에러 0
