## 개발 적용 (Changelog)

### 2026-08-03 — 블록을 몬스터로 · 매치 시 죽는 표정 (v7.6)

- 6색 블록을 **몬스터 6종**으로 교체: 초록 좀비(비대칭 눈·스티치) · 흰 스켈레톤(해골·이빨) · 빨강 데몬(뿔·송곳니) · 파랑 슬라임(큰 눈·물방울) · 보라 유령(빈 눈) · 주황 호박(꼭지·잭오랜턴). 색을 **서로 확실히 구분되게**(초록/흰/빨강/파랑/보라/주황) 선택
- **매치되어 사라질 때 죽는 표정**: X자 눈 + 벌린 입 + 혀로 바뀌며 쪼그라들어 "죽는 느낌". 클리어 애니메이션 시간을 늘려 표정이 보이게 함
- 특수 블록 표시를 몬스터 위 오버레이(줄무늬/폭탄 테두리)로 조정, 레인보우 무지개 색도 몬스터 팔레트에 맞춤. 버전 v7.6

### 2026-08-03 — 특수 조합 · ㄱ자 매치 · 콤보 · UI 개편 (v7.5)

- **특수 블록끼리 스와이프 = 조합 효과**: 줄+줄 = 십자, 줄+폭탄 = 3칸 십자, 폭탄+폭탄 = 5×5, 레인보우+줄 = 해당 색 전부 줄 발동, 레인보우+폭탄 = 해당 색 전부 폭탄, 레인보우+레인보우 = 보드 전체
- **ㄱ자(L/T) 매치도 특수 블록**: 가로 런과 세로 런이 교차하는 코너에 폭탄 생성(교차 감지 추가)
- **콤보**: 한 수에서 연쇄가 이어질수록 `COMBO xN` 배너가 뜨고 점수 배수 증가
- **UI 개편**: 인게임 HUD를 패널 + STAGE/MOVES 알약(pill) + 글로우 진행바로 정리
- 버전 라벨 `v7.5`

### 2026-08-03 — Pointer Events 전환 · 버전 라벨 (v7.4)

- 입력을 **Pointer Events**(pointerdown/up)로 전환 — 마우스·터치·펜 통합, `touches/changedTouches` 함정 자체를 제거해 모바일 스와이프를 근본적으로 안정화. `setPointerCapture`로 드래그 추적
- 캔버스 우측 하단에 **빌드 버전 라벨**(`VERSION`) 표시 — 라이브가 최신 수정본인지 한눈에 확인(캐시 여부 판별)

### 2026-08-03 — 모바일 터치 스와이프 수정

- `touchend`는 좌표가 `changedTouches`에 있는데 `e.touches[0]`(빈 리스트)을 읽어 NaN이 되던 문제 → `changedTouches` 우선 사용
- 화면→캔버스 좌표 매핑을 `BOARD_H`(430) 대신 실제 캔버스 크기 `CANVAS_H`(516, HUD 포함)로 스케일 → 세로 위치 정확
- 두 수정으로 모바일에서 슬라이드(스와이프) 및 탭 교체가 정상 동작

### 2026-08-03 — 인게임 HUD · 특수 더블탭 발동 · 이펙트

- **HUD를 캔버스 안으로**: HTML 스탯 박스 제거, 캔버스 상단에 스테이지·점수·목표 **진행바**·이동 렌더(그리드는 그 아래로 오프셋, 보드 영역 클립)
- **특수 블록 더블탭/더블클릭 발동**: 특수 블록을 두 번 탭하면 제자리에서 즉시 터뜨림(이동 1 소모). 레인보우는 가장 많은 색을 제거
- **이펙트 추가**: 블록 제거 시 팝(확장 링), 줄 삭제 빔(가로/세로), 폭탄 링(확장 원), 레인보우 화면 플래시

### 2026-08-03 — 초기 구현

- **8×8 3매치 코어**: 인접 교체 → 매치 감지(가로/세로 3+) → 제거 → 중력/리필 → **연쇄(캐스케이드)**. 매치 없는 교체는 되돌림
- **2×2 스퀘어도 유효 매치**로 처리(라인 3매치와 별개)
- **특수 블록 생성 규칙**: 가로4 → 줄(행 삭제), 세로4 → 줄(열 삭제), 2×2 → 폭탄(3×3), 5매치 → 레인보우(같은 색 전체). 특수는 스왑 위치에 우선 앵커
- **특수 발동·연쇄**: 특수가 매치에 휩쓸리면 발동하고, 효과 범위에 든 다른 특수를 BFS로 연쇄. 레인보우는 스왑으로 색 전체 제거
- **스테이지 10개**: 이동 횟수 안에 목표 점수 달성 → 다음 스테이지, 실패 시 재시도. 캐스케이드 점수 배수
- **리셔플 가드**: 가능한 수가 없으면 색을 섞어 항상 진행 가능
- 상태 머신(idle→swap→clearing→falling→cascade) + 블록 트윈, Canvas 렌더(글로시 블록·특수 장식·연쇄 축소 이펙트), 탭/드래그 입력, 고해상도(DPR)
- 검증: 헤드리스 로직 테스트(매치 감지·특수 생성·연쇄·중력·4000수 안정성) 통과, 브라우저 콘솔 에러 0
