## 개발 적용 (Changelog)

### 2026-08-03 — 박쥐가 매치 정리 전에 즉시 날아감 (v7.32)

- **박쥐 동시 발사**: 매치/폭발로 박쥐가 사라질 때, 매치가 다 정리되길 기다리지 않고 **터지는 애니메이션 도중에 곧바로 날아가게** 했다. 별도 페이즈로 막지 않고 클리어/낙하와 동시에 비행(`autoBats`), 착탄 시 그 자리를 제거

### 2026-08-03 — 전체 속도 상향(터지는·낙하) (v7.31)

- **터지는 속도 빠르게**: `CLEAR_LIFE` 30→16(팝 지속 절반), 젬 트윈 `EASE` 0.3→0.42(스왑·낙하 더 빨리 안착)로 연쇄 한 스텝이 대략 2배 빨라짐
- **유도탄도 스냅하게**: 비행 `dur` 26→18, 순차 발사 간격도 단축
- **박쥐 즉시 발동**: 3매치 등으로 박쥐가 사라지면 연쇄가 다 끝나길 기다리지 않고 그 매치가 정리되는 즉시 날아가게(`_afterFall` 앞단에서 대기 박쥐 먼저 발사)

### 2026-08-03 — 폭탄+박쥐: 폭탄이 제자리 폭발 후 박쥐 발동 (v7.30)

- **폭탄 + 박쥐 스와이프**: 박쥐가 폭탄을 배달(deliver)하던 것을 바꿔, 폭탄이 제자리에서 3×3 터지며 그 범위에 든 박쥐를 휩쓸고 → 그 박쥐가 발동해 날아가게. (폭탄 범위에 박쥐 포함 → 박쥐 발동)
- 참고: 폭탄이 다른 경로(더블탭·아이템·연쇄)로 터질 때 범위 안의 박쥐가 발동하는 건 기존에도 동작(v7.26)

### 2026-08-03 — 특수 조합이 원래효과를 대체 (v7.29)

- **조합은 원래효과 발동 없이 조합효과만**: 두 특수를 조합하면 각자의 원래 효과는 발동하지 않고(제자리에서 일반 블럭처럼 제거) 조합효과만 발동
- **폭죽+폭죽 = 스와이프한 자리에서 십자**(가로 한 줄 + 세로 한 줄). 기존의 가로+세로 2줄씩에서 깔끔한 십자로
- 폭죽+폭탄(3열 십자)·폭탄+폭탄(5×5)도 동일하게 원래효과 없이 조합효과만

### 2026-08-03 — 박쥐 스와이프 발동 제거(더블탭만) (v7.28)

- **박쥐+일반 스와이프는 발동 안 함**: 박쥐를 일반 블럭과 스와이프하면 그냥 자리 교환(다른 특수처럼 매치가 되면 그때 발동). 발동은 **더블탭**으로만. 박쥐+특수 조합은 기존대로 스와이프로 발동

### 2026-08-03 — 폭죽 삼각 머리·꼬리 제거·2×2 포함 5매치=박쥐 (v7.27)

- **폭죽 그래픽**: 도화선·별 스파크(꼬리) 제거, 머리를 뾰족한 삼각형으로(줄무늬 몸통 유지)
- **2×2 포함 5매치 = 박쥐**: 2×2 모양을 포함한 5매치는 박쥐(유도탄), 순수 ㄱ/ㄴ/T(2×2 없음) 교차만 폭탄으로

### 2026-08-03 — 박쥐(유도탄) 어떤 방식으로 터져도 발동 (v7.26)

- **박쥐가 어떻게 제거되든 발동**: 3매치·액티브 아이템·다른 특수블럭 폭발 등 어떤 방식으로 박쥐가 사라져도, 연쇄가 끝난 뒤 그 박쥐들이 최적 위치로 유도되어 날아가게(기존엔 직접 스왑/더블탭할 때만 발동)

### 2026-08-03 — 폭죽 그래픽·5매치 판정·조합 이펙트·무지개+박쥐 (v7.25)

- **폭죽(일자) 그래픽**: 추상 버스트 대신 줄무늬 로켓 + 도화선 + 별 스파크의 폭죽 모양으로
- **2×2/5매치 판정 수정**: 2×2가 5매치(ㄱ/ㄴ/T)의 일부일 땐 폭탄으로. 순수한 2×2(4칸)만 유도탄(박쥐)
- **조합 이펙트**: 일자+일자=십자, 일자+폭탄=가로3·세로3을 빔으로 한 번에 터지게
- **무지개+박쥐 수정**: 그 색이 전부 박쥐로 변할 때 각 박쥐가 최적 위치로 유도되어 날아가게(기존엔 유도 안 됨)

### 2026-08-03 — 특수블럭 재편(유도탄/폭탄 분리)·조합·그래픽 (v7.24)

- **매치 모양 → 특수블럭 재정의**: 2×2 = 유도탄(박쥐), ㄱ/ㄴ/T 5매치 = 폭탄(3×3), 가로/세로 4 = 일자(폭죽), 5일자 = 무지개
- **특수 조합표**:
  - 일자 + 일자 = 십자(가로줄+세로줄) — 방향 무관, 제자리
  - 일자 + 폭탄 = 3열 십자 — 제자리
  - 폭탄 + 폭탄 = 5×5 — 제자리
  - 무지개 + 특수 = 그 색이 모두 조합 특수로 변한 뒤 순차 발동
  - 특수 + 유도탄 = 유도되는 위치로 박쥐가 날아가 그 특수가 거기서 발동
  - 유도탄 + 유도탄 = 유도탄(박쥐) 3개
- **그래픽**:
  - 유도탄 = 로켓 대신 박쥐(블럭 네모 없이), 날아갈 때도 날개 퍼덕이는 박쥐
  - 일자 = 로켓 대신 폭죽(별 모양으로 터지는 스파크, 지우는 방향으로 길게)
  - 폭탄·유도탄도 일자처럼 젬 색상을 가짐

### 2026-08-03 — 유도탄 순차 발사 (v7.23)

- **유도탄 여러 개는 동시에 안 나가고 순서대로**: 폭탄+폭탄=유도탄 3개가 12프레임(약 0.2초)씩 간격을 두고 차례로 발사되게(발사 전엔 조준 레티클만 표시, 발사 순간마다 효과음)

### 2026-08-03 — 호박 잭오랜턴 복원 (v7.22)

- **호박 얼굴을 잭오랜턴으로 되돌림**: 둥근 눈+이빨 버전보다 이전 삼각 눈·지그재그 입 버전이 낫다는 피드백 반영

### 2026-08-03 — 유도탄 전용 그래픽·비행 궤적 강화 (v7.21)

- **유도탄 블럭 그래픽 새로**: 폭탄 구체와 똑같던 걸, 빨간 탄두 + 금속 동체 + 핀 + 조준 레티클이 달린 유도탄 모양으로 바꿔 4매치 로켓·색폭탄과 확실히 구분
- **비행 궤적 강화**: 유도탄이 더 천천히 날며(dur 16→26) 긴 꼬리를 남기게 — 궤적을 점이 아닌 끝으로 갈수록 굵어지는 테이퍼 스트릭(+밝은 코어)으로 렌더

### 2026-08-03 — 폭탄 유도탄화·알람/이펙트 지속·호박·악마 (v7.20)

- **2×2 폭탄 = 유도탄**: 3×3 광역 대신, 가장 큰 연쇄를 일으키는 칸을 자동 조준해 날아가 블럭 1개 제거(없으면 다른 특수블럭→가장 흔한 색 중앙 순으로). 폭탄을 스왑/더블탭하면 발사
- **특수조합도 최적 위치로 비행**: 줄+줄(십자)·줄+폭탄(3열 십자)은 최적 칸으로 날아가 발동
- **유도탄+유도탄 = 유도탄 3개**: 서로 다른 최적 칸 3곳으로
- **저이동 경보 더 오래**: "N회 남음!" 배너를 약 2초 더 보이게(84→210프레임), 깜빡임은 프레임 기준으로 바꿔 속도 유지
- **이펙트 조금 더 길게**: 빔/링/플래시/스매시/소용돌이/팝 지속 프레임 소폭 상향
- **호박 더 귀엽게**: 삼각 눈·지그재그 입 대신 둥근 눈 + 작은 이빨 그린
- **악마**: 송곳니와 볼터치 제거(더 귀엽게)

### 2026-08-03 — 악마·해골·귀신 몬스터 리디자인 (v7.19)

### 2026-08-03 — 특수블록 배경 제거·로켓/폭탄/색폭탄 리디자인·악마·콤보 (v7.16)

- **특수블록에서 몬스터 배경 제거**: 특수블록은 색 몬스터 바디 없이 심볼만 크게 그린다(4매치 후 색이 뒤에 남던 문제 해결)
- **4매치 = 로켓**: 줄을 지우는 방향으로 나는 로켓(가로 줄=가로 로켓, 세로 줄=세로 로켓). 색은 해당 젬 색으로 유지
- **폭탄 리디자인**: 배경 없이 더 큰 다크 스피어로, 심지·불꽃을 셀 안에 담아 위쪽 블록과 겹치지 않게
- **색폭탄(레인보우) 리디자인**: 별 제거, 무지개 스프링클이 박힌 광택 다크 오브로
- **악마 그래픽 수정**: 굽은 뿔, 빛나는 아몬드형 눈+세로 동공, 성난 눈썹, 송곳니 그린으로 또렷하게
- **콤보 표시 정리**: 체인 끝에 마지막 콤보가 다시 튀어나오던 것 제거. 콤보를 약 1.7초 보여주고 천천히 페이드, 다음 체인이 이어지면 즉시 교체되어 사라지게

### 2026-08-03 — 특수블록 전용 그래픽·색폭탄 리디자인·아이템 아이콘·순차 발동 (v7.15)

- **특수블록을 전용 그래픽으로**: 몬스터 얼굴 위에 겹쳐 그리던 방식을 버리고, 특수블록은 몬스터 없이 **색 바디 + 전용 심볼**만 그린다(줄=에너지 밴드+양끝 화살촉, 폭탄=심지·불꽃 달린 폭탄 구체). 기본 몬스터 블록과 시각적으로 구분
- **색폭탄(레인보우) 그래픽 리디자인**: 어두운 바디 위에 클리핑된 무지개 원반 + 광택 + 흰 테두리 + 별 스파클로 새로 그림
- **몬스터 블록 개선**: 컨셉·색상은 유지하고 **테두리 림 + 상단 광택**을 더해 어두운 보드에서 형태가 또렷하게
- **액티브 아이템 아이콘 개선**: 흰색 라인 아이콘 + 아이템별 **광택 컬러 타일**(외곽선·드롭섀도로 가시성↑), 톤앤매너 통일(망치/섞기/폭탄/십자/색폭탄)
- **줄+폭탄 조합**: 가로·세로 각각 3열씩 한 번에 제거(3-wide 십자)
- **레인보우+특수 순차 발동**: 색폭탄을 줄/폭탄과 스왑하면 **그 색 블록이 전부 해당 특수로 변한 뒤**, 한 번에 터지지 않고 **하나 터지고→블록 내려오고→또 터지는** 순차 연쇄로 발동

### 2026-08-03 — 저이동 경보·콤보 지속·특수/아이템 그래픽 (v7.14)

- **이동 5회 이하 경보**: 처음 5회 이하가 되면 "N회 남음!" 경고 배너 + **비상벨 1회**, 배경음 템포 상승(임계 3→5)
- **콤보 표시 개선**: 연쇄 중엔 최신 콤보만 짧게, **체인이 끊긴 마지막 콤보는 오래**(약 1.3초) 남아 잘 보이게
- **아이템 장착 UI 정리**: 보드 깜빡임·설명 배너 제거(범위 프리뷰는 유지), 버튼 펄스도 정적 하이라이트로
- **하단 설명 문구 제거**
- **특수 블록 그래픽 새로 그림**: 줄(가로/세로)은 에너지 밴드+화살촉·셰브론, 폭탄은 심지·불꽃 달린 폭탄 케이싱으로 — 단순 줄 대신 블록 형태
- **액티브 아이템 아이콘을 채워진 컬러 그래픽**으로 교체(망치/섞기/폭탄/십자/색폭탄)

### 2026-08-03 — 옵션 모달 개편·일시정지·진동 정리 (v7.13)

- **옵션을 화면 중앙 모달로**: 톱니를 누르면 배경음/효과음/진동을 **아이콘 토글**(끄면 빨간 사선)로 표시하는 가운데 모달이 뜸. 열려 있는 동안 **게임 일시정지**(보드 프리즈), 배경 클릭·닫기로 재개
- **진동 옵션은 터치 지원 기기에서만 표시**: `navigator.vibrate` + 터치(`maxTouchPoints`) 조건. `.opt[hidden]`이 `.opt{display:flex}`에 덮이던 CSS 버그 수정으로 PC에서 실제로 숨김
- **진동 값 단순화**(매치 18ms / 특수 패턴)로 호환성 향상, 진동을 켤 때 즉시 테스트 진동으로 지원 확인. (iOS Safari는 Vibration API 미지원이라 옵션 자체가 안 보임)

### 2026-08-03 — 옵션 패널·햅틱·BGM 변주·저이동 템포 (v7.12)

- **옵션 패널(톱니바퀴)**: 우측 상단 톱니 버튼으로 열리는 패널에서 **배경음·효과음·진동** 각각 켜기/끄기. 설정은 localStorage에 저장. 진동 행은 `navigator.vibrate` 지원(모바일)에서만 표시
- **햅틱 피드백**: 매치 시 **약하게**(짧은 진동), 폭탄·특수·조합 발동 시 **강하게**(패턴 진동). 진동 옵션이 꺼져 있으면 동작 안 함
- **배경음악 2스테이지마다 변주**: 스테이지 그룹(`floor(stage/2)`)마다 루프의 근음(키)을 바꿔 분위기 전환
- **저이동 템포 상승**: 남은 이동이 **3 이하**면 배경음 템포가 빨라져 긴박함을 줌
- 오디오 모듈을 효과음/배경음 독립 제어로 리팩터링(기존 단일 음소거 → 개별 토글)

### 2026-08-03 — 아이템 범위 프리뷰 · 실패 시 골드로 이어하기 (v7.11)

- **아이템 범위 프리뷰**: 아이템을 장착하고 **대상 위에 커서를 올리거나(모바일은 손가락을 대고 드래그)** 하면, 그 아이템이 지울 칸들이 노란 하이라이트로 **미리 표시**됨(망치=한 칸, 폭탄=3×3, 십자=가로·세로 줄, 색폭탄=같은 색 전체). 장착 배너에 효과 설명 추가. 프리뷰/발동이 같은 `itemCells()`를 공유해 표시와 결과 일치
- **이어하기**: 이동을 다 써서 실패하면 **골드를 내고 +3회** 이어할 수 있음. 비용은 재실패할수록 2배로 증가(100 → 200 → 400 …), 스테이지 클리어/다시 시작 시 초기화. 골드가 모자라면 이어하기 버튼 비활성
- 장착 버튼 펄스에서 위치 이동 제거(글로우만)

### 2026-08-03 — 아이템 장착 피드백·발동 이펙트·가격 차등·랜덤 보상 (v7.9)

- **장착(선택) 피드백**: 아이템을 누르면 보드에 노란 틴트 + 상단 배너("○○ 사용 · 대상을 탭 · 다시 누르면 취소"), 해당 버튼은 노란 펄스 애니메이션으로 강조 — 쓰기 전에 어떤 아이템이 장착됐는지 명확
- **아이템별 발동 이펙트**: 망치=강타(방사 임팩트), 폭탄=폭발 링, 십자=가로·세로 빔, 색폭탄=화면 플래시, 섞기=소용돌이
- **아이템별 가격 차등**(성능 반영): 망치 60 · 섞기 90 · 폭탄 140 · 십자 170 · 색폭탄 240G. 시작 골드 200으로 상향, 아이템 바를 가격 오름차순 정렬
- **스테이지 클리어 랜덤 아이템**: 골드 보상에 더해 랜덤 아이템 1개 지급(클리어 화면에 표시)

### 2026-08-03 — 액티브 아이템·골드·힌트·난이도·배경음악 (v7.8)

- **골드 경제**: 새 게임 시작 시 골드 150 + 아이템 각 2개. **스테이지 클리어 시 골드 획득**(기본 60 + 남은 이동 ×10). 아이템이 0개일 때 아이콘을 누르면 **골드로 구매**(개당 120G, 부족하면 구매 불가). 아이템/골드는 스테이지 넘어가도 유지, 처음부터 시작 시 초기화

- **배경음악**: Web Audio로 마이너 아르페지오 루프를 실시간 합성(오디오 파일 없음). 음소거 토글이 SFX+음악을 함께 제어, 첫 제스처에서 시작

### 2026-08-03 — 초기 구현

- **8×8 3매치 코어**: 인접 교체 → 매치 감지(가로/세로 3+) → 제거 → 중력/리필 → **연쇄(캐스케이드)**. 매치 없는 교체는 되돌림
- **2×2 스퀘어도 유효 매치**로 처리(라인 3매치와 별개)
- **특수 블록 생성 규칙**: 가로4 → 줄(행 삭제), 세로4 → 줄(열 삭제), 2×2 → 폭탄(3×3), 5매치 → 레인보우(같은 색 전체). 특수는 스왑 위치에 우선 앵커
- **특수 발동·연쇄**: 특수가 매치에 휩쓸리면 발동하고, 효과 범위에 든 다른 특수를 BFS로 연쇄. 레인보우는 스왑으로 색 전체 제거

- **리셔플 가드**: 가능한 수가 없으면 색을 섞어 항상 진행 가능
- 상태 머신(idle→swap→clearing→falling→cascade) + 블록 트윈, Canvas 렌더(글로시 블록·특수 장식·연쇄 축소 이펙트), 탭/드래그 입력, 고해상도(DPR)
