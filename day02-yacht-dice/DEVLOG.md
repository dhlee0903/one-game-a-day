### 2026-07-28 — 똑똑한 봇 · 실수 방지 · 하이스코어

**봇 강화**
- 홀드를 **몬테카를로 기대값**으로 결정(후보 keep-set별 리롤 시뮬레이션 후 최선 선택)
- 카테고리 선택에 상단 보너스 가중 + 고득점 칸 낭비 회피
- 솔로 시뮬 평균 ~163점 (기존 단순 그리디 대비 강해짐)

**실수 방지 + 연출**
- 점수칸 클릭 → **선택(확인 바)** → 확정. 같은 칸 재클릭 = 확정, 취소 버튼 제공
- 확정 시 숫자가 **손글씨처럼 써지는 애니메이션**
- Yacht·스트레이트·풀하우스·상단 보너스 달성 시 **축하 팝업**

**하이스코어·전적**
- `localStorage`에 최고 총점 + vs 봇 승/패/무 기록, 셋업 화면에 표시
- 신기록 시 게임오버에 "🎉 신기록!"

### 2026-07-28 — 종이 테마 & 폰트

- **점수판을 실제 종이 스코어시트처럼** — 크림색 배경, 다크 잉크, 괘선, 그림자
- **예쁜 폰트** — 본문 `Jua`(둥근 서체), 점수 칸 `Gaegu`(손글씨체)로 종이에 적은 느낌
- 전체 글자 크기 확대(본문 17 / 차례 24 / 점수 24 / 버튼 20px 등)
- 폰트는 Google Fonts(유일한 외부 에셋), 미로딩 시 시스템 폰트로 폴백

### 2026-07-28 — 굴림 애니메이션 & 봇 연출

- **주사위 굴림 애니메이션** — 방금 굴린 주사위가 튀어오르며 회전(고정한 주사위는 제외)
- **봇 "생각하는" 연출** — 단계별 페이싱(굴림→남길 주사위 표시→멈춤→재굴림→점수칸 선택),
  각 단계에 "🤔 생각 중…" 상태 메시지 표시 → 봇이 뭘 하는지 눈으로 따라갈 수 있음
- 상태 메시지는 주사위를 건드리지 않고 턴 줄만 갱신(굴림 애니메이션 재생 방지)
