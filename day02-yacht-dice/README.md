# Day 02 · 야추 다이스 (Yacht Dice)

주사위 5개로 12칸을 채우는 야추(야추다이스/Yahtzee 계열) 게임.
**vs 봇** 또는 **vs 사람(핫시트, 한 기기에서 번갈아)** 로 대전.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버가 필요합니다.

```bash
npx serve .
# 또는
python -m http.server 8000
```

## 구조

```
day02-yacht-dice/
├── index.html          # 셋업/게임/오버레이 마크업, 모듈 진입점
├── css/style.css
└── src/
    ├── config.js       # 상수 + 카테고리 표 (single source of truth)
    ├── scoring.js      # 순수 점수 계산 함수 (카테고리별)
    ├── game.js         # 턴/굴림/승패 상태 머신
    ├── bot.js          # 봇 전략 (고정 판단 · 카테고리 선택)
    ├── renderer.js     # DOM 렌더링 (주사위 · 점수판)
    ├── input.js        # 클릭 → 게임 명령 매핑
    └── main.js         # DOM 연결 · 셋업/오버레이 · 봇 드라이버
```

단방향 의존: `config ← scoring ← {game, bot} ← main`. 렌더러는 상태를 읽기만 함.

## 규칙

- 한 턴에 **최대 3번** 주사위를 굴린다. 남기고 싶은 주사위를 클릭해 **고정**하고 나머지를 다시 굴린다.
- 굴림이 끝나면 비어 있는 **점수칸 하나**에 확정한다.
- 12칸을 모두 채우면 종료, **총점**이 높은 쪽이 승리.

### 점수표

| 카테고리 | 점수 |
| --- | --- |
| Aces~Sixes | 해당 눈의 합 |
| 상단 보너스 | 상단 합 63 이상 → **+35** |
| Choice | 전체 주사위 합 |
| 4 of a Kind | 같은 눈 4개 → 전체 합 |
| Full House | 3+2 → 전체 합 |
| S. Straight | 4연속 → 15 |
| L. Straight | 5연속 → 30 |
| Yacht | 같은 눈 5개 → 50 |

## 조작

- **주사위 굴리기** 버튼 → 굴림 (턴당 3회)
- **주사위 클릭** → 고정/해제
- **점수칸 클릭** → 그 칸에 확정 (미리보기 점수 표시)

## 모드

- **vs 봇**: 봇은 가장 많은 눈을 남기며 굴리고, 매 턴 가장 높은 점수의 빈 칸을 고르는 그리디 전략.
- **vs 사람**: 같은 기기에서 한 턴씩 번갈아 플레이 (온라인 아님).
