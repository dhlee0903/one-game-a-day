# Day 01 · 테트리스

바닐라 JS + Canvas로 만든 테트리스. ES 모듈로 관심사를 분리했습니다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버가 필요합니다.

```bash
npx serve .
# 또는
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 구조

```
day01-tetris/
├── index.html          # 마크업 + 캔버스, 모듈 진입점 로드
├── css/style.css       # 스타일
└── src/
    ├── config.js       # 상수: 보드 크기, 블록 정의, 점수 규칙
    ├── tetromino.js    # 블록 모델 + 7-bag 랜덤화
    ├── board.js        # 그리드 상태, 충돌 판정, 줄 제거
    ├── renderer.js     # Canvas 렌더링 (고스트/NEXT 포함)
    ├── input.js        # 키보드 + 터치/스와이프 입력
    ├── game.js         # 게임 루프, 점수, 레벨, 상태 머신
    └── main.js         # DOM 연결, 오버레이 관리
```

각 모듈은 단방향 의존만 갖습니다: `config ← {tetromino, board, renderer} ← game ← main`.

## 기능

- 7종 블록 + **7-bag 랜덤** (블록 가뭄 방지)
- **SRS 정식 월킥** 회전(벽·바닥 킥, T-스핀 가능), 반시계 회전(Z)
- **홀드(Hold)** — 드롭당 1회, 블록 보관/교체
- **고스트 피스**, HOLD/NEXT 미리보기
- 소프트/하드 드롭, 레벨별 낙하 속도 증가
- 1·2·3·4줄 차등 점수 (Single/Double/Triple/Tetris)
- **라인 클리어 애니메이션** (플래시 + 와이프)
- **가이드라인 점수** — 콤보, **백투백(×1.5)**, **T-스핀** 인식·보너스 + 팝업
- 일시정지, 게임오버 → 재시작
- 모바일: 터치 버튼 + 스와이프(좌우 이동 / 아래 드롭 / 탭 회전)

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 좌우 이동 |
| ↓ | 소프트 드롭 |
| ↑ / X | 회전 |
| Z | 반시계 회전 |
| Shift | 홀드 |
| Space | 하드 드롭 |
| P | 일시정지 |
