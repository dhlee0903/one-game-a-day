# Day 01 · 테트리스 — 개발 로그

이 게임의 **개발 예정**과 **개발 적용** 내역을 한 파일에서 관리한다.
항목을 구현하면 `개발 예정`에서 지우고 `개발 적용`에 날짜와 함께 옮긴다.

---

## 🚧 개발 예정 (Planned)

우선순위 높은 순.

- [ ] **홀드(Hold)** — `C`키로 현재 블록 보관/교체, 홀드 미리보기 칸
- [ ] **SRS 정식 월킥** — 표준 회전 오프셋 테이블 적용 (T-스핀 가능)
- [ ] **라인 클리어 애니메이션** — 줄 삭제 시 플래시/디졸브 + 콤보·점수 팝업
- [ ] **최고 점수 저장** — `localStorage`에 하이스코어 기록/표시
- [ ] **레벨·속도 곡선 조정** — 후반 난이도 밸런싱
- [ ] **사운드** — 이동/회전/락/라인클리어 효과음, 음소거 토글

## ✅ 개발 적용 (Changelog)

### 2026-07-27 — 초기 구현 & 배포

**게임 기능**
- 7종 블록 + **7-bag 랜덤화** (블록 가뭄 방지)
- 월킥 회전(단순 오프셋), 반시계 회전(`Z`)
- **고스트 피스**(착지 위치 미리보기), **NEXT** 미리보기
- 소프트 드롭 / 하드 드롭
- 레벨별 낙하 속도 증가, 1·2·3·4줄 차등 점수
- 일시정지(`P`), 게임오버 → 재시작
- 모바일: 터치 버튼 + 보드 스와이프(좌우 이동 / 아래 드롭 / 탭 회전)
