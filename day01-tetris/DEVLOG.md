## ✅ 개발 적용 (Changelog)

### 2026-07-27 — 백투백 & T-스핀 (가이드라인 점수)

- **T-스핀 인식** — 3-코너 규칙(회전이 마지막 동작 + 코너 3개 이상 막힘),
  전면 코너로 full/mini 구분, 큰 월킥 시 full 승격
- **가이드라인 점수표** — T-Spin 400 / Single 800 / Double 1200 / Triple 1600,
  Mini 100 / Single 200
- **백투백(B2B)** — 테트리스·T-스핀 라인클리어를 연속하면 라인 점수 ×1.5
- T-스핀은 라인 0줄이어도 점수 인정, 팝업에 `T-SPIN DOUBLE`·`BACK-TO-BACK` 표기
- 이동/드롭/회전별 "마지막 동작" 추적 추가(T-스핀 판정용)

### 2026-07-27 — 콤보 (Combo)

- 연속으로 줄을 지우면 **콤보** 누적, 콤보 보너스 = `50 × 콤보 × 레벨`
- 줄을 못 지운 락에서 콤보 초기화
- 클리어 시 **팝업** 표시 — SINGLE/DOUBLE/TRIPLE/TETRIS + `COMBO ×N`

### 2026-07-27 — 라인 클리어 애니메이션

- 줄 삭제를 즉시 처리하지 않고 **플래시 + 가운데→바깥 와이프**(약 260ms) 후 붕괴
- 게임 루프에 `clearAnim` 상태 추가 — 애니메이션 중 입력·중력 정지
- `board.clearLines()` → `fullRows()`(감지) + `removeRows()`(제거)로 분리

### 2026-07-27 — 홀드 키 변경

- 홀드 키를 `C` → **`Shift`** 로 변경 (README·조작 안내 갱신)

### 2026-07-27 — SRS 정식 월킥

- 회전 로직을 단순 수평 킥(`[0,-1,1,-2,2]`)에서 **표준 SRS 킥 테이블**로 교체
  (J·L·S·T·Z 공용 / I 전용, 각 회전 전이별 5개 오프셋)
- 블록에 회전 상태(`rotation` 0·1·2·3) 추적 추가 → 전이별 킥 조회
- 벽·바닥 킥이 제대로 동작 → **T-스핀** 등 고급 기술 가능
- O 블록은 회전 스킵(킥 불필요)
- 검증: 콘솔 에러 0, 회전 4-사이클 일관성, 좌벽/바닥 회전 인바운드 유지

### 2026-07-27 — 홀드(Hold)

- `C`키(모바일 홀드 버튼)로 현재 블록 보관/교체
- 사이드 패널에 **HOLD** 슬롯 추가 (NEXT와 나란히 배치)
- **드롭당 1회 제한** — 홀드 쿨다운 중에는 슬롯을 흐리게 표시, 블록이 락되면 재활성화
- 렌더러의 미리보기 로직을 HOLD/NEXT 공용(`_drawPreview`)으로 리팩터
- (버그 수정) 보관 필드 `hold`가 `hold()` 메서드를 가리던 섀도잉 → 필드를 `heldPiece`로 개명

### 2026-07-27 — 초기 구현 & 배포

**게임 기능**
- 7종 블록 + **7-bag 랜덤화** (블록 가뭄 방지)
- 월킥 회전(단순 오프셋), 반시계 회전(`Z`)
- **고스트 피스**(착지 위치 미리보기), **NEXT** 미리보기
- 소프트 드롭 / 하드 드롭
- 레벨별 낙하 속도 증가, 1·2·3·4줄 차등 점수
- 일시정지(`P`), 게임오버 → 재시작
- 모바일: 터치 버튼 + 보드 스와이프(좌우 이동 / 아래 드롭 / 탭 회전)
