# SKY RAID · Day 09

1945풍 종스크롤 슈팅. 바다 위를 날며 적 편대를 격추하고 **3스테이지**의 보스를 모두 잡으면 클리어.
그래픽은 도트(픽셀 아트) — 스프라이트를 코드 안 픽셀맵으로 한 점씩 찍어서 외부 이미지가 없다.
기체는 좌우 대칭이라 **왼쪽 절반 + 가운데 열**만 찍고 굽는 시점에 되접는다.

## 조작

- **모바일**: 화면을 **드래그**하면 기체가 손가락을 따라온다(손가락이 기체를 가리지 않는 상대 이동 방식). **사격은 자동**.
- **PC**: 방향키 또는 WASD로 이동, 사격은 자동.
- 드래그와 키보드는 **같은 최대 속도**를 쓴다. 손가락에 1:1로 붙이지 않고 상한을 걸어, 어느 쪽으로 조작해도 기체가 같은 속도로 움직인다.
- 좌우로 움직이면 기체가 **그 방향으로 기운다**.
- **폭탄**: 우하단 `BOMB` 버튼 또는 `Space` / `X`
- **일시정지**: 좌하단 톱니바퀴 버튼, PC는 `Esc` 또는 `P`. 탭을 벗어나면 저절로 멈춘다.
- **스테이지 시작 대기**: 스테이지가 시작되면 기체가 화면 아래에서 날아 올라와 가운데에 자리를 잡고, **첫 조작이 들어올 때까지** 배경만 흐르는 제자리 비행 상태로 기다린다. 움직이거나 폭탄을 쓰면 그때 편대가 나온다.
  - 이전 스테이지부터 **잡고 있던 드래그로는 시작되지 않는다.** 손가락(마우스)을 뗐다가 다시 잡아야 한다 — 보스를 잡느라 화면을 누르고 있던 손이 다음 스테이지를 곧바로 열어버리지 않게.

모바일에서는 페이지 헤더를 걷어내고 화면 전체를 쓴다. 페이지가 스크롤되지 않으므로 드래그하다 당겨서 새로고침되거나 다른 화면으로 밀려나지 않는다.

## 규칙

- 목숨 3개로 시작. 적 탄이나 기체에 닿으면 1개를 잃고, **무기가 한 단계 내려가며 보조기는 사라진다.**
- 격추되면 그 자리에서 즉시 부활하지 않는다. 잠깐 사라졌다가 **화면 아래에서 시작 위치로 날아 들어오고**, 그동안은 조작할 수 없다. 복귀 후에는 잠시 깜빡이며 무적.
- 목숨을 다 쓰면 게임 오버.
- 폭탄은 **화면의 적 탄을 모두 지우고** 모든 적에게 큰 피해를 준다. 쓰는 동안 잠깐 무적.

## 아이템

편대를 전멸시키면 떨어진다.

| 아이템 | 효과 | 한계 |
| --- | --- | --- |
| **P** | 무기 강화 1단계 | 5단계까지 |
| **O** | 보조기 추가 — 양옆에서 직선탄을 함께 쏜다 | 2기까지 |
| **B** | 폭탄 +1 | 5개까지 |
| **L** | 목숨 +1 | 없음 |

한계에 도달한 상태로 먹으면 대신 200점. 아이템 자체 점수는 50점.

**보스를 격파하면 P와 B가 떨어진다.** 스테이지가 넘어가도 떨어진 아이템은 사라지지 않으니, 다음 스테이지 대기 중에 주우면 된다.

### 무기 강화 5단계

| 단계 | 사격 |
| --- | --- |
| 1 | 단발 |
| 2 | 2연 (평행) |
| 3 | 3방향 (직선 + 좌우 확산) |
| 4 | 4연 (평행 2 + 확산 2) |
| 5 | 5방향 (직선 + 평행 2 + 넓은 확산 2) |

피격하면 한 단계 내려가고 보조기는 모두 사라진다.

## 적

| 적 | 특징 |
| --- | --- |
| 초록 전투기 | 직진, 사격 없음 |
| 노랑 전투기 | 좌우로 흔들리며 내려오고 가끔 조준 사격 |
| 빨강 급강하기 | 등장 시점의 플레이어를 향해 빠르게 돌진 |
| 회색 폭격기 | 중간에서 멈춰 조준 3방향 사격, 체력이 높다 |

## 스테이지

무기·보조기·폭탄·목숨은 다음 스테이지로 그대로 이어진다.

| 스테이지 | 배경 | 보스 체력 | 특징 |
| --- | --- | --- | --- |
| 1 · PACIFIC | 한낮 열대 바다 | 260 | 기본 편성 |
| 2 · SUNSET STRAIT | 해질녘 해협 | 380 | 잡몹 체력 +1, 적 탄속 1.12배 |
| 3 · NIGHT RAID | 야간 강습 | 520 | 잡몹 체력 +1, 적 탄속 1.24배, 보스 공격 주기 최단 |

## 보스

체력이 줄면 3페이즈로 바뀌며 패턴이 거세진다. 스테이지마다 도장(팔레트)이 다르다.

1. 조준 확산탄 · 링탄 (느슨)
2. 확산탄 증가 · 빠른 조준탄
3. 이중 링탄 + 고속 확산탄

## 배경

깊이를 만들려고 층을 나눠 서로 다른 속도로 흘린다. 층마다 오프스크린에 한 번만 굽고 매 프레임은 blit만 한다.

| 층 | 속도 | 내용 |
| --- | --- | --- |
| 수심 밴드 | 고정 | 깊이별 단색 + 경계 디더링 |
| 깊은 물 | 0.45x | 흐릿한 얼룩 · 해류 |
| 수면 | 1.0x | 잔물결 · 윤슬 · 암초 · 섬 · 배와 항적 |
| 구름 | 1.9x | **기체 위**를 지나간다 — 가장 강한 원근 단서 |

## 점수

적 격추 점수 + 보스 5,000 / 8,000 / 12,000점 + 스테이지 넘길 때마다 2,000점.
최종 클리어 시 **남은 폭탄 300점, 남은 목숨 500점** 보너스.
최고 점수는 `localStorage`에 저장되고 홈 카드에도 표시된다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 실행한다.

```bash
cd day09-shooter && npx serve .
# 또는
python -m http.server 8000
```
