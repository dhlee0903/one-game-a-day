# SKY RAID · Day 09

1945풍 종스크롤 슈팅. 밝은 바다 위를 날며 적 편대를 격추하고 마지막 보스를 잡으면 클리어.
그래픽은 도트(픽셀 아트) — 스프라이트를 코드 안 픽셀맵으로 그려서 외부 이미지가 없다.

## 조작

- **모바일**: 화면을 **드래그**하면 기체가 손가락 움직임만큼 따라온다(손가락이 기체를 가리지 않는 상대 이동 방식). **사격은 자동**.
- **PC**: 방향키 또는 WASD로 이동, 사격은 자동.
- **폭탄**: 우하단 `BOMB` 버튼 또는 `Space` / `X`

## 규칙

- 목숨 3개로 시작. 적 탄이나 기체에 닿으면 1개를 잃고, **무기가 한 단계 내려가며 보조기는 사라진다.**
- 피격 후 잠시 무적. 목숨을 다 쓰면 게임 오버.
- 폭탄은 **화면의 적 탄을 모두 지우고** 모든 적에게 큰 피해를 준다. 쓰는 동안 잠깐 무적.

## 아이템

편대를 전멸시키면 떨어진다.

| 아이템 | 효과 |
| --- | --- |
| **P** | 무기 강화 (1→4단계: 단발 → 2연 → 3방향 → 5방향) |
| **O** | 보조기 추가 (최대 2기, 양옆에서 함께 사격) |
| **B** | 폭탄 +1 (최대 5) |
| **L** | 목숨 +1 |

## 적

| 적 | 특징 |
| --- | --- |
| 초록 전투기 | 직진, 사격 없음 |
| 노랑 전투기 | 좌우로 흔들리며 내려오고 가끔 조준 사격 |
| 빨강 급강하기 | 등장 시점의 플레이어를 향해 빠르게 돌진 |
| 회색 폭격기 | 중간에서 멈춰 조준 3방향 사격, 체력이 높다 |

## 보스

체력이 줄면 3페이즈로 바뀌며 패턴이 거세진다.

1. 조준 확산탄 · 링탄 (느슨)
2. 확산탄 증가 · 빠른 조준탄
3. 이중 링탄 + 고속 확산탄

## 점수

적 격추 점수 + 보스 5,000점. 클리어 시 **남은 폭탄 300점, 남은 목숨 500점** 보너스.
최고 점수는 `localStorage`에 저장되고 홈 카드에도 표시된다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 실행한다.

```bash
cd day09-shooter && npx serve .
# 또는
python -m http.server 8000
```
