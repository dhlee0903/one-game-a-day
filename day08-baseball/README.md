# 숫자야구 · Day 08

서로 다른 숫자로 이루어진 정답을 추리하는 고전 숫자야구(Bulls and Cows).
자리와 숫자가 모두 맞으면 **스트라이크(S)**, 숫자만 맞으면 **볼(B)**, 하나도 없으면 **아웃**.

## 규칙

- 정답은 **서로 다른 숫자**로 구성된다. 숫자는 `0-9`, 맨 앞자리 `0`도 나올 수 있다.
- 같은 숫자를 두 번 넣을 수 없다(이미 쓴 키는 눌리지 않는다).
- 모든 자리를 맞히면 승리, 시도를 다 쓰면 패배.

| 난이도 | 자리수 | 시도 제한 | 정답 후보 |
| --- | --- | --- | --- |
| 3자리 | 3 | 10회 | 720 |
| 4자리 | 4 | 12회 | 5,040 |

## 조작

- **키패드 탭** 또는 **숫자 키(0-9)** 로 입력
- **확인** 또는 **Enter** 로 제출 (자리수를 다 채워야 활성화)
- **지우기** 또는 **Backspace** 로 한 칸 지우기, **전체 지우기** / **Esc** 로 비우기

## 도움 기능

- **후보 수**: 지금까지의 판정과 모순되지 않는 남은 정답 후보 개수를 보여준다. 기록에는 영향 없다.
- **힌트**(판당 1회): 한 자리의 숫자를 공개한다. 해당 자리 슬롯에 노란 점선으로 표시된다.
  힌트를 쓴 판은 **최소 기록에 등록되지 않는다**.

## 기록

- **최소 시도 횟수**를 난이도별로 저장한다(적을수록 좋음). 통산 판수·승수도 함께 기록.
- 저장은 브라우저 `localStorage`. 홈 화면 카드에도 최소 시도가 표시된다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 실행한다.

```bash
cd day08-baseball && npx serve .
# 또는
python -m http.server 8000
```
