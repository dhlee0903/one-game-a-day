# Day 08 · 숫자야구 — 개발 로그

`개발 예정`과 `개발 적용`을 한 파일에서 관리. 구현하면 예정에서 지우고 적용에 날짜와 함께 옮긴다.

## 개발 예정 (Planned)

- [ ] 효과음 (입력·스트라이크·아웃·승리)
- [ ] 자리수 5 이상 / 시간 제한 모드
- [ ] 추리 보조: 자리별로 확정/제외된 숫자를 표에 표시
- [ ] 결과 공유용 텍스트(시도별 S/B 요약) 복사

## 개발 적용 (Changelog)

### 2026-08-04 — 4자리 고정·중복 추측 허용 (v8.3)

- **4자리만** 남기고 3자리 난이도 제거. 난이도 토글도 없애고 그 자리에 규칙 칩(`4자리 · 중복 입력 가능`)을 뒀다
- **추측에 중복 숫자 허용**: 정답은 여전히 서로 다른 숫자지만, 입력은 `0011`·`1111`처럼 같은 숫자를 여러 번 넣을 수 있다. 특정 숫자의 포함 여부를 캐는 전략적 탐색이 가능해진다
- **판정을 멀티셋 기반으로 수정**: 기존 로직은 `indexOf`로 세서 정답 1234 / 추측 1111을 `1S 3B`로 잘못 판정했다. 이제 숫자별 `min(정답 개수, 추측 개수)` 합에서 스트라이크를 빼는 방식이라 `1S 0B`로 올바르게 나온다
- 키패드가 이미 쓴 숫자를 더 이상 잠그지 않는다(자리를 다 채웠을 때만 잠금)
- 시도 제한 12회 유지 — 중복 프로빙 전략 시뮬레이션에서 500판 전부 12수 내 성공(최악 9수, 평균 6.6수)

### 2026-08-04 — 라이트 테마 전환·UI 개선 (v8.2)

- **부드러운 라이트 테마**: 어두운 남색 배경을 걷어내고 흰 카드 + 연한 청회색 배경 + 소프트 섀도로 전환. 판정 배지는 밝은 배경에서도 또렷하게(스트라이크 초록 / 볼 파랑 / 아웃 회색), 주 버튼은 파란색, 기록·힌트는 앰버로 역할을 색으로 구분
- **후보 수를 토글 버튼 안에 표시**: 별도 칸(`남은 후보`)을 없애고 버튼 라벨이 `후보 수` → `후보 720`으로 바뀌게 했다. 켜고 꺼도 **레이아웃이 흔들리지 않는다**(기존엔 칸이 생겨 슬롯이 밀렸다)
- **다음 입력 자리 표시**: 채워질 슬롯에 파란 링을 둘러 어디를 입력하는 중인지 보이게
- **비활성 확인 버튼을 중립색으로**: 흐린 파랑이라 고장난 것처럼 보였던 걸 회색으로 바꿔 "아직 자리수가 안 찼다"는 뜻이 읽히게
- **남은 시도 경고색**: 3회 이하로 떨어지면 붉게
- **새 기록 줄 등장 애니메이션**: 새로 추가된 시도 줄만 살짝 페이드인(매 렌더마다 반복되지 않게 직전 개수와 비교)

### 2026-08-04 — 첫 버전 (v8.1)

- **기본 규칙**: 서로 다른 숫자로 된 정답, 자리+숫자 일치 = 스트라이크(S), 숫자만 일치 = 볼(B), 둘 다 없으면 아웃. 맨 앞자리 0 허용
- **난이도 2종**: 3자리(시도 10회) / 4자리(시도 12회). 헤드리스로 공정성 확인 — 단순 전략(남은 후보 첫 항목 추측)의 최악값이 3자리 9회·4자리 8회로 제한 안에 들어온다
- **입력**: 키패드 탭 + 물리 키보드(숫자/Enter/Backspace/Esc). 이미 쓴 숫자 키는 비활성, 자리수를 다 채우기 전엔 확인 버튼 비활성
- **시도 기록**: 최신이 위로 오는 목록에 숫자와 S/B 배지(스트라이크 초록·볼 파랑·아웃 회색) 표시
- **후보 수 표시(토글)**: 지금까지의 판정과 모순되지 않는 남은 정답 후보 개수. 기록에는 영향 없음
- **힌트(판당 1회)**: 한 자리의 숫자를 공개하고 슬롯에 점선으로 고정 표시. 쓰면 그 판은 최소 기록에서 제외
- **기록 저장**: 난이도별 **최소 시도 횟수**(적을수록 좋음)와 통산 판수·승수를 localStorage에 저장. 홈 카드에도 최소 시도를 노출
- 구조: 규칙·후보 추론·상태 머신을 DOM과 분리해 노드에서 그대로 테스트 가능하게 구성

#### 구현 중 잡은 것

- `new Game(...)` 생성 중에 `onChange`가 불려 아직 초기화되지 않은 `game` 상수를 참조하던 TDZ 오류 → 콜백이 인스턴스를 인자로 받게 수정
- `.stat { display: flex }`가 `[hidden]`을 덮어 후보 수 칸이 꺼져도 보이던 문제 → `.stat[hidden] { display: none }` 추가
