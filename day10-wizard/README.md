# Day 10 · 아케인 서바이벌 (Arcane Survival)

뱀파이어 서바이벌 계열의 생존 게임. 조작은 **이동뿐**이고 공격은 전부 자동으로 나간다.
적을 잡아 경험치 보석을 모으고, 레벨업 때마다 카드 세 장 중 하나를 골라 빌드를 쌓는다.
**15분을 버티면 클리어.**

그래픽은 도트. 모든 그림은 소스에 문자열 픽셀맵으로 들어 있고, 시작할 때
**스프라이트시트(아틀라스) 한 장으로 구워서** 거기서 잘라 쓴다. 이미지 파일은 하나도 없다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 띄운다.

```bash
cd day10-wizard && npx serve .
# 또는
python -m http.server 8000
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 · WASD | 이동 |
| 화면 끌기(모바일) | 누른 자리에 가상 스틱이 생긴다 |
| Esc · P · 톱니 버튼 | 일시정지 |
| F2 | 구워진 스프라이트시트 보기(개발용) |

공격 · 조준 버튼은 없다. 무기는 각자의 재사용 대기시간마다 알아서 나간다.

## 시스템

**무기** (최대 5개 · 각 6레벨)

| 무기 | 방식 |
| --- | --- |
| 마력 화살 | 가장 가까운 적을 자동 조준 |
| 서리 파편 | 바라보는 방향으로 관통 투사체 |
| 수호 룬 | 몸 주위를 공전하며 닿은 적을 때린다 |
| 화염 오라 | 주변을 지속 피해 + 넉백 |
| 연쇄 번개 | 화면 안 임의의 적에게 낙뢰 |
| 불의 낙인 | 발밑에 불장판을 남긴다 |

**패시브** (최대 5개 · 각 6레벨) — 마력(공격력) · 신속(이동) · 생명력(최대 체력) ·
집중(재사용 대기) · 확장(범위) · 자석(획득 범위) · 지혜(경험치) · 재생

**진행** — 시간대별로 적 구성과 소환 간격이 바뀐다. 중간중간 포위 · 무리 · 엘리트가
끼어들고 5 · 10 · 14분에 보스(리치)가 나온다. 엘리트와 보스는 상자를 떨구고,
상자를 먹으면 무기 하나가 그 자리에서 한 단계 오른다.

**기록** — 생존 시간(초)을 최고 기록으로 남긴다. 홈 화면 카드와 같은 키(`og-hs-day10`)를 쓴다.

## 구조

```
day10-wizard/
├── index.html          # 마크업 + 오버레이(타이틀 · 레벨업 카드 · 일시정지)
├── css/style.css
└── src/
    ├── config.js       # 상수 (single source of truth)
    ├── sprites.js      # 픽셀맵 · 팔레트 · 스프라이트시트 굽기 · 5×7 도트 글꼴
    ├── anim.js         # 애니메이션 클립과 프레임 진행
    ├── weapons.js      # 무기 정의(레벨표) + 발사 로직
    ├── upgrades.js     # 패시브 정의 + 레벨업 카드 뽑기
    ├── spawner.js      # 시간대별 소환과 사건(포위 · 엘리트 · 보스)
    ├── game.js         # 상태와 규칙 (그리지 않는다)
    ├── renderer.js     # 읽기 전용 렌더러 (아틀라스에서 잘라 그린다)
    ├── input.js        # 키보드 + 가상 스틱
    ├── storage.js      # 최고 기록
    └── main.js         # DOM 연결 · 고정 타임스텝 루프
```

의존 방향은 아래로만 흐른다. `config.js`가 맨 밑이고 렌더러는 상태를 **읽기만** 한다.

## 스프라이트시트

`src/sprites.js`의 `MAPS`가 프레임 정의 전부다. 한 글자가 한 도트이고, 글자의 뜻은
프레임이 쓰는 팔레트(`PAL`)가 정한다.

- 좌우 대칭인 큰 그림(리치)은 **왼쪽 절반 + 가운데 열**만 찍고 구울 때 뒤집어 붙인다(`mirror`).
- 프레임마다 `lift`(0/1)를 줄 수 있다. 발밑 기준으로 그리므로 걷는 동안 몸이 한 도트씩 뜬다.
- 바닥 타일은 시드 고정 난수로 잡티를 흩뿌려 만든다(손으로 16×16 노이즈를 찍는 건 고치기 어렵다).
- 굽기 전에 `validateMaps()`가 줄 길이와 팔레트에 없는 글자를 잡아 콘솔에 찍는다.

`buildSheet()`는 프레임을 높이순으로 선반(shelf) 배치해 캔버스 한 장에 채우고
`{ canvas, tinted, frames }`를 돌려준다. `tinted`는 피격 순간에 쓰는 흰색 실루엣 사본으로
좌표계가 같아 프레임 표를 그대로 쓴다.

애니메이션은 `anim.js`의 클립(`frames` · `hold` · `loop`)으로 제어한다. 개체가 수백이라
적은 `Animator` 인스턴스 대신 자기 나이(`t`)만 갖고 `frameAt(clip, t)`로 프레임을 꺼낸다.
