# Day 11 · 길건너 친구들

원작 **Crossy Road**를 최대한 비슷하게 옮긴 엔드리스 게임. 도로·강·철길을 건너
얼마나 멀리 갈 수 있는지 겨룬다.

라이브러리 없이 **직접 만든 3D 렌더러**로 그린다. Three.js 같은 것 없이
원근 투영 + 페인터 알고리즘으로 복셀 박스를 캔버스에 직접 래스터화한다.

---

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 띄운다.

```bash
cd day11-crossy && npx serve .
# 또는
python -m http.server 8000
```

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 앞으로 | `↑` `W` `Space` | 화면 탭 |
| 좌 · 우 | `←` `→` `A` `D` | 좌 · 우 스와이프 |
| 뒤로 | `↓` `S` | 아래로 스와이프 |
| 다시 하기 | 아무 키 (결과 화면에서) | 화면 탭 |

점수와 최고 기록은 화면 좌측 상단에 계속 보인다. 기록을 넘어서면 그 자리에서 올라간다.

## 규칙

- **점수는 가장 멀리 간 줄 수.** 뒤로 갔다 와도 최고 기록은 유지된다.
- **차 · 기차에 치이면 즉사.** 철길은 기차가 오기 전 건널목 신호기가 빨갛게 깜빡인다.
- **강은 통나무를 타고 건넌다.** 물에 그냥 빠지면 익사하고, 통나무를 타고
  화면 밖까지 떠내려가도 죽는다.
- **시점은 계속 앞으로 천천히 밀린다.** 멈춰 있으면 그만큼 화면 아래로
  내려가고, 화면 바닥에 닿을 즈음 독수리가 잡아간다. 위험해지면 화면
  가장자리가 붉게 경고한다.
- **나무 · 바위는 막힌다.** 부딪히면 그 수는 날아간다.
- **가끔 넓은 평야**가 나온다. 장애물이 거의 없고 꽃과 코인이 흩뿌려진 구간으로,
  다른 지형보다 드물게(대략 60줄에 한 번) 나온다.
- **코인**을 모으면 시작 화면에서 캐릭터를 살 수 있다(오리 · 고양이 · 강아지).

## 소리

파일 없이 WebAudio 오실레이터·노이즈로만 만든다.

- 건널목에 기차가 오면 **땡땡땡** 종이 울리고, 지나갈 때 **슈우우웅** 소리가 난다
  (노이즈를 밴드패스로 훑어 지나가는 느낌을 낸다).
- 근처에 차가 있으면 **가끔** 경적이 울린다(9~22초에 한 번).
- 독수리가 덮칠 때는 떨림을 얹은 **울음소리**가 난다.
- 그 밖에 점프 · 착지 · 코인 · 사망음.

## 3D는 어떻게 그리나

의존성 제로 규칙을 지키면서 3D를 내려면 렌더러를 직접 써야 했다.

- **카메라**: yaw는 0으로 고정한 원근 카메라. 그래야 차선이 화면과 수평으로
  눕고(원작의 그 구도), 화면 좌우 끝의 블록만 원근 때문에 옆면이 드러난다.
  초점거리를 길게 잡아 직교 투영에 가깝게 — 복셀 특유의 납작한 느낌을 낸다.
- **박스 래스터화**: 박스마다 꼭짓점 8개를 투영하고, 바깥 법선이 카메라를
  향하는 면만 남긴 뒤(백페이스 컬링) 면 방향에 따라 밝기를 달리해 채운다.
  윗면 > 앞면 > 왼쪽 > 오른쪽 순으로 밝다.
- **깊이 정렬**: 박스 중심의 카메라 공간 z로 먼 것부터 그린다(페인터 알고리즘).
  위에 얹힌 물체는 중심이 높아 깊이가 자연히 작아지므로 나중에 그려진다.
- **틈 메우기**: 맞닿은 면 사이로 배경이 비치는 실금은, 면마다 stroke를 얹는
  대신 폴리곤을 무게중심 기준으로 0.7px 부풀려 없앴다(더 싸다).
- **묶어 그리기**: 체크무늬 바닥·침목처럼 같은 평면에 겹치지 않게 늘어선
  사각형은 한 번의 `fill()`로 처리한다.
- **멀리 잘라내기**: 화면 밖 차량·나무는 그 줄의 가시 폭을 계산해 건너뛰고,
  먼 줄은 지면만 그린 뒤 하늘색 안개로 덮어 지평선을 만든다.
