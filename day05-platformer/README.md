# Day 05 · 횡스크롤 플랫포머 (Platformer)

바닐라 JS + Canvas로 만든 마리오풍 횡스크롤 액션. 스테이지 3개를 달리며 코인을 먹고,
? 블록에서 아이템을 꺼내고, 적을 밟아 처치하고, 벽돌을 부수고, 깃발을 타고 내려오면 다음 스테이지로.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버가 필요합니다.

```bash
npx serve .
# 또는
python -m http.server 8000
```

## 구조

```
day05-platformer/
├── index.html          # 캔버스 + HUD + 터치 버튼
├── css/style.css
└── src/
    ├── config.js       # 상수 (타일 타입·물리·색)
    ├── level.js        # 스테이지 3개 생성 (타일 그리드 + 코인/적/골)
    ├── physics.js      # AABB 타일 충돌 (밑에서 친 블록 리포트)
    ├── player.js       # 플레이어 (이동·가변 점프·큰/작은 상태)
    ├── enemy.js        # 적 (순찰·벽/절벽 반전·밟기)
    ├── item.js         # 버섯 아이템 (블록에서 솟아 걷기)
    ├── game.js         # 루프 · 블록 · 아이템 · 깃발 · 스테이지 · 상태
    ├── renderer.js     # Canvas 렌더 (카메라 오프셋)
    └── main.js         # DOM 연결 · 입력 · 오버레이
```

단방향 의존: `config ← level/physics ← player/enemy/item ← game ← main`. 렌더러는 상태를 읽기만 함.

## 조작

| 입력 | 동작 |
| --- | --- |
| ← → / A D | 이동 |
| ↑ / W / Space | 점프 (길게 누르면 더 높이) |
| 적 위로 착지 | 밟아 처치 (+바운스) |
| (모바일) 화면 버튼 | 이동 · 점프 |

## 규칙

- **코인** +50, **적 밟기** +100, **버섯** +1000, **벽돌 부수기** +20
- **? 블록**: 밑에서 치면 코인 또는 버섯이 나옴 (한 번 쓰면 빈 블록)
- **버섯**을 먹으면 커지고(big), 피격 시 죽지 않고 작아짐(잠깐 무적)
- **벽돌**은 큰 상태에서 밑을 쳐야 부서짐 · **동전 벽돌**은 여러 번 쳐서 동전 획득
- 적에 옆으로 닿거나 **구덩이에 빠지면** 목숨 -1 (기본 3)
- **깃발**을 타고 내려오면 다음 스테이지로, 스테이지 3개를 모두 클리어하면 올 클리어
