## 개발 적용 (Changelog)

### 2026-07-29 — 밝은 테마 · 입력 · 이펙트 · 충돌 연출

- **밝은 테마 + 체커보드 보드**로 격자를 또렷하게
- 그리드 **16×16으로 축소**(칸 크게, 27px)
- **입력 큐** — 방향 전환을 2개까지 버퍼링해 벽 앞 빠른 코너 전환에도 안 씹힘
- **먹기/성장 이펙트** — 먹은 자리에 링 + 파티클 버스트
- **충돌 연출** — 죽을 때 머리가 부딪힌 칸으로 이동하고 그 방향을 향하게 + 빨간 임팩트 링,
  잠깐(0.55s) 보여준 뒤 게임오버 → 왜 죽었는지 명확
- 시작 속도 완화(200ms), 가속 3ms, 최고 속도 100ms

### 2026-07-29 — 초기 구현

- 클래식 스네이크: 그리드 이동, 먹이 성장, 벽·자기 충돌 게임오버
- 먹을수록 **속도 증가**(틱 감소, 최소값까지), 180° 역주행 방지
- 입력: 방향키 / WASD / 모바일 스와이프, 일시정지(P/Space)
- **최고 점수** localStorage 저장 + 신기록 표시
- Canvas 렌더링(라운드 몸통, 머리 눈, 발광 먹이)
- ES 모듈 관심사 분리(`config·snake·game·renderer·input·storage·main`)
- GitHub Pages 배포
